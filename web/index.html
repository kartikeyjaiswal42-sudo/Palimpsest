What this tool gets wrong

    Measured on held-out data and reported here because a detector that hides its error rates is not an instrument. Full numbers in docs/03-evaluation.md.

    The language model is read for token probabilities only — it is never asked for a verdict. Your essay is sent to Cloudflare Workers AI to be scored, because the observer is a 30-billion-parameter model that is not run in this process. It is not stored or logged by this application, but it does leave this machine. To score entirely locally, restart with PALIMPSEST_OBSERVER=gpt2.
